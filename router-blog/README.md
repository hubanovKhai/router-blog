# Блог на React Router v8

Навчальний багатосторінковий SPA-застосунок, розроблений у межах лабораторної роботи з React Router v8.

## Виконані рівні
- **Рівень 1:** базові маршрути, спільний макет (`Outlet`), навігація (`NavLink`), сторінка 404.
- **Рівень 2:** пошук за назвою та фільтрація за автором через query-параметри (`useSearchParams`), редирект `/blog` → `/`.
- **Рівень 3:** data-режим (`createBrowserRouter` + `RouterProvider`), завантаження даних через `loader`, обробка помилок через `ErrorBoundary`, індикатор завантаження (`useNavigation`), ліниве завантаження сторінки «Про нас» (`lazy`).
- **Рівень 4:** контекст авторизації (`AuthContext`), захищені маршрути (`ProtectedRoute`), збереження адреси повернення після входу, модульні тести на Vitest + React Testing Library, конфігурація деплою для Netlify та Vercel.
- **Рівень 5:** повноцінний CRUD постів через локальну REST-базу даних `json-server` (`db.json`), обробка форм через `<Form>` та `action`, валідація (`useActionData`), перевірка прав автора (403 для чужих постів), сторінка «Мої пости».

## Список маршрутів
| Маршрут | Опис | Доступ |
| --- | --- | --- |
| `/` | Головна сторінка зі списком постів, пошуком і фільтром | Усі |
| `/posts/:postId` | Перегляд окремого поста | Усі |
| `/posts/new` | Створення нового поста | Лише авторизовані |
| `/posts/:postId/edit` | Редагування поста | Лише автор поста |
| `/posts/:postId/destroy` | Action-маршрут для видалення поста | Лише автор поста |
| `/admin` | Особистий кабінет «Мої пости» | Лише авторизовані |
| `/login` | Вхід або реєстрація користувача | Усі |
| `/about` | Сторінка «Про нас» (lazy-завантаження) | Усі |
| `/blog` | Редирект на `/` | Усі |
| `*` | Сторінка 404 | Усі |

## Запуск проєкту

```bash
# Встановлення залежностей
npm install

# Одночасний запуск json-server (порт 3001) та Vite (порт 5173)
npm run dev

# Одноразовий запуск тестів
npm test -- --run
```

Тестові облікові записи: `Олена` / `1234` або `Андрій` / `1234`.
